ESP32 NeoPixel Tetris

Flash the firmware directly from your browser (no IDE required).

Requirements

  • Google Chrome or Microsoft Edge (Web Serial is required).
  • A data-capable USB cable (charge-only cables will not work).
  • An ESP32-S3 dev board (default build: esp32-s3-devkitc-1).

Install / Update

If the button is disabled, your browser likely does not support Web Serial. See the ESP Web Tools documentation.

Tip: If your board does not show up as a serial device, try a different USB port/cable, and ensure any required USB-to-serial drivers are installed.
